# Superpowers Workflow Index
这是一个完整的多Agent工作流（Superpowers）。当用户请求开发新功能或复杂任务时，必须严格按照以下顺序调用相关规则（Skills）：
1. brainstorming (需求风暴与架构拆解)
2. writing-plans (编写实现计划)
3. executing-plans (执行计划)
4. test-driven-development (测试驱动开发)
5. systematic-debugging (系统性调试)
6. verification-before-completion (完成前验证)

你已加载所有子规则，请作为一套完整的工作流运作，不要遗漏任何环节。
